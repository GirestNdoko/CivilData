CivilData

CivilData est un projet d'application d'analyse de données destiné à faciliter le suivi et la gestion des activités dans le domaine du génie civil.

Module initial : Fabrication

Le premier module est consacré aux entreprises qui fabriquent des matériaux de construction.

Il doit permettre de :

- gérer les produits fabriqués ;
- enregistrer les productions, les ventes et les pertes ;
- suivre les stocks ;
- conserver l'historique des opérations sur plusieurs mois et années ;
- gérer les prix de vente et les coûts de fabrication ;
- analyser les résultats financiers ;
- produire des statistiques et des prévisions ;
- générer des rapports périodiques exportables en PDF.

Organisation du projet

- "docs/" : documentation et spécifications ;
- "data/" : données de test et jeux de données ;
- "src/" : code source ;
- "tests/" : tests et vérifications.
